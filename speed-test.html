About this test & server setup

Ping is the median of eight small round trips; jitter is the mean absolute difference between consecutive round trips. Download and upload are measured from bytes actually received or sent over a short multi-connection window. Browser timing, Wi‑Fi, other traffic, server load, and the path to the server affect results. This is a practical estimate, not a carrier-grade measurement.

Start the included server with python3 speedtest_server.py, then open http://127.0.0.1:8080/. It serves this page and provides uncached download, upload, and ping endpoints. The same routes deploy to Vercel from app.py. Each upload request is 2 MB so it stays under Vercel’s request-body limit. For any public host, use HTTPS and a nearby region with enough network capacity, restrict allowed origins with SPEEDTEST_ALLOWED_ORIGINS, and set sensible bandwidth, rate, body-size, and concurrency limits. The dependency-free Python server is a local demo; put it behind a reverse proxy before exposing it directly.

The page always measures the host it was opened from, so the test server is chosen in the background. Open it from the local server or the Vercel deployment and the ping, download, and upload requests stay on that same address. Caches and CDNs must bypass these routes; the endpoints use no-store headers and unique request URLs.
